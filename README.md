## 📖 Overview

EduTrack is a cross-platform academic management application developed using **.NET MAUI** and the **MVVM architectural pattern**.

The application is designed to simplify the management of examinations, schedules, and academic performance while providing a modern user experience across multiple platforms.

---

## ✨ Features

- 🔐 User Authentication (Login & Signup)
- 📅 Exam Schedule Management
- 🗓️ Academic Timetable
- 📆 Interactive Exam Calendar
- 📊 Result Summary Dashboard
- 👤 Student Profile
- 🔔 Confirmation Popups
- 📱 Cross-platform UI
- ⚡ MVVM Architecture
